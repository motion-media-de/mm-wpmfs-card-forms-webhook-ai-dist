# Card Forms Webhook & AI — Releases

Dieses Repository enthält **ausschließlich die fertigen Release-Pakete** des
WordPress-Plugins `mm-wpmfs-card-forms-webhook-ai`. Der Quellcode wird hier nicht veröffentlicht.

Webhook-Anbindung und Ergebnisseiten für Card Forms.

## Wozu dieses Repository dient

Installationen des Plugins fragen hier nach neuen Versionen. Dadurch erscheinen
Updates ganz normal im WordPress-Plugins-Bildschirm — ohne Zusatz-Plugin und
ohne Zugangsdaten auf der Website.

Damit das ohne Token funktioniert, ist dieses Repository öffentlich. Der
Quellcode liegt getrennt davon und ist es nicht.

## Installation

Das ZIP der gewünschten Version unter [Releases](../../releases) herunterladen und in
WordPress unter **Plugins → Installieren → Plugin hochladen** einspielen.
Danach kommen Updates automatisch.

## Versionen

Jedes Release trägt den Tag `v<version>` und genau ein Paket namens
`mm-wpmfs-card-forms-webhook-ai-<version>.zip`. Der Changelog steht in der `readme.txt` im Paket und in
den Release-Notes.
